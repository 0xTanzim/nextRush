If you're upgrading an existing NextRush v3 app that still uses `app.plugin()`, `Plugin`, or
`controllersPlugin`, see the
[Extension Model migration guide](https://github.com/0xTanzim/nextrush/blob/main/docs/guides/migration-extension-model.md)
— it covers the breaking change from the plugin system to middleware, registrars, and
Extensions, and is not yet folded into the consolidated section above.
