## Category legend

| Category | Meaning |
| --- | --- |
| Core | Foundation packages (`types`, `errors`, `core`, `router`, `runtime`, `stream`) plus the `nextrush` meta package that re-exports them |
| Platform | Runtime adapters — connect `Application` to a specific runtime's HTTP primitives (grouped under `reference/platforms/` per the [Adapter Contract](/docs/architecture/contracts)) |
| Class Runtime | Decorators, DI, controllers, modules, guards, interceptors, filters (`@nextrush/class`, `@nextrush/di`) |
| Middleware | `app.use()`-registered, per-request capability — the ~99% default idiom (see [Capability Composition](/docs/architecture/capability-composition)) |
| Middleware / Plugin | Middleware-idiom packages that predate the "plugin" terminology retirement — functionally identical to Middleware, kept as a distinct tag only because their docs historically lived under a `plugins/` folder before this reference was flattened |
| Extension | Long-lived, app-scoped services registered with `app.extend()` |
| Development | Build-time and CLI tooling, not runtime dependencies of a deployed app |
