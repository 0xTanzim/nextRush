## Which package do I need?

Start with `nextrush` — it includes routing, middleware, and the Node.js server. Add a package only when a specific need comes up:

| I want to…                         | Install                                                           | Reference                                                  |
| ----------------------------------- | ------------------------------------------------------------------ | ------------------------------------------------------------ |
| Parse JSON / form request bodies    | `@nextrush/body-parser`                                            | [body-parser](/docs/reference/body-parser)                   |
| Handle file uploads (multipart)     | `@nextrush/form-data`                                               | [form-data](/docs/reference/form-data)                        |
| Validate requests (Zod/Valibot/ArkType) | `@nextrush/validation`                                          | [validation](/docs/reference/validation)                      |
| Generate OpenAPI docs from routes   | `@nextrush/openapi`                                                 | [openapi](/docs/reference/openapi)                             |
| Stream AI/LLM responses (SSE, NDJSON) | `@nextrush/stream`                                                | [stream](/docs/reference/stream)                               |
| Allow cross-origin requests (CORS)  | `@nextrush/cors`                                                    | [cors](/docs/reference/cors)                                   |
| Set security headers                | `@nextrush/helmet`                                                  | [helmet](/docs/reference/helmet)                               |
| Rate-limit endpoints                | `@nextrush/rate-limit`                                              | [rate-limit](/docs/reference/rate-limit)                       |
| Compress responses (gzip/brotli)    | `@nextrush/compression`                                             | [compression](/docs/reference/compression)                     |

| Add request IDs for tracing         | `@nextrush/request-id`                                              | [request-id](/docs/reference/request-id)                       |
| Measure response time               | `@nextrush/timer`                                                   | [timer](/docs/reference/timer)                                 |
| Liveness/readiness probes           | `@nextrush/health`                                                  | [health](/docs/reference/health)                               |
| Serve static files                  | `@nextrush/static`                                                  | [static](/docs/reference/static)                                |
| Add WebSocket support                | `@nextrush/websocket`                                               | [websocket](/docs/reference/websocket)                          |
| Render HTML templates                | `@nextrush/template`                                                | [template](/docs/reference/template)                            |
| Emit structured logs                 | `@nextrush/logger`                                                  | [logger](/docs/reference/logger)                                 |
| Use a type-safe event emitter        | `@nextrush/events`                                                  | [events](/docs/reference/events)                                 |
| Build class-based controllers        | `@nextrush/class`                                                   | [class](/docs/reference/class)                                    |

| Run on Bun, Deno, Edge, or serverless | `@nextrush/adapter-bun` · `-deno` · `-edge` · `-serverless`         | [platforms](/docs/reference/platforms)                              |
| Hot-reload dev server & build        | `@nextrush/dev`                                                     | [dev](/docs/reference/dev)                                          |

The full catalog with size budgets is in [Packages A-Z](/docs/reference/packages).

## Quick Start

For most projects, install the meta package:

<PackageInstall packages={['nextrush']} />

This gives you:

- `createApp()` — Application factory
- `createRouter()` — Router factory
- `listen()` — Start Node.js server
- HTTP error classes
- Essential types

```typescript
import { createApp, createRouter, listen } from 'nextrush';

const app = createApp();
const router = createRouter();

router.get('/', (ctx) => ctx.json({ hello: 'world' }));

app.route('/', router);
await listen(app, 8080);
```

## Package Categories

### Core Foundation

The foundational packages that everything else builds on.

| Package                                              | Purpose                             | Install Separately?                                                   |
| ----------------------------------------------------- | ------------------------------------ | ------------------------------------------------------------------------ |
| [`nextrush`](/docs/reference/nextrush)                | Meta package with all essentials    | **Start here**                                                        |
| [`@nextrush/core`](/docs/reference)              | Application, middleware composition | Usually via `nextrush`                                                |
| [`@nextrush/router`](/docs/reference/router)          | Segment trie routing                | Usually via `nextrush`                                                |
| [`@nextrush/types`](/docs/reference/types)            | TypeScript type definitions         | Re-exported by `nextrush`; install directly for advanced package work |
| [`@nextrush/errors`](/docs/reference/errors)          | HTTP error classes                  | Usually via `nextrush`                                                |
| [`@nextrush/runtime`](/docs/reference/runtime)        | Runtime detection                   | Usually via adapter                                                   |
| [`@nextrush/dev`](/docs/reference/dev)                | Development server & build tools    | **Dev dependency**                                                    |

### Platforms

| Package                                                     | Runtime                   | Notes                  |
| ------------------------------------------------------------ | ---------------------------- | ------------------------- |
| [`@nextrush/adapter-node`](/docs/reference/platforms/node)   | Node.js                   | Included in `nextrush` |
| [`@nextrush/adapter-bun`](/docs/reference/platforms/bun)     | Bun                       | Install separately     |
| [`@nextrush/adapter-deno`](/docs/reference/platforms/deno)   | Deno                      | Install separately     |
| [`@nextrush/adapter-edge`](/docs/reference/platforms/edge)   | Edge (Cloudflare, Vercel) | Install separately     |
| [`@nextrush/adapter-serverless`](/docs/reference/platforms/serverless) | AWS Lambda and other event-driven platforms | Install separately |

## Choosing Packages

### Functional Style (Recommended for Most)

```typescript
import { createApp, createRouter, listen } from 'nextrush';
import { cors } from '@nextrush/cors';
import { json } from '@nextrush/body-parser';

const app = createApp();
app.use(cors());
app.use(json());

const router = createRouter();
router.get('/users', (ctx) => ctx.json([]));

app.route('/', router);
await listen(app, 8080);
```

**Install:**

<PackageInstall packages={['nextrush', '@nextrush/cors', '@nextrush/body-parser']} />

### Class-Based Style (For Larger Apps)

```typescript
import { createApp, listen } from 'nextrush';
import { registerControllers, Controller, Get, Service } from 'nextrush/class';

@Service()
class UserService {
  findAll() {
    return [{ id: 1, name: 'Alice' }];
  }
}

@Controller('/users')
class UserController {
  constructor(private users: UserService) {}

  @Get()
  findAll() {
    return this.users.findAll();
  }
}

const app = createApp();
await registerControllers(app, { root: './src', prefix: '/api' });
await listen(app, 8080);
```

**Install:**

<PackageInstall packages={['nextrush', '@nextrush/class']} />

### Non-Node.js Runtimes

For Bun, Deno, or Edge runtimes, install the specific adapter:

```typescript
// Bun
import { createApp } from '@nextrush/core';
import { serve } from '@nextrush/adapter-bun';

const app = createApp();
serve(app, { port: 8080 });
```

**Install:**

<PackageInstall packages={['@nextrush/core', '@nextrush/router', '@nextrush/adapter-bun']} />

## Package Size Philosophy

NextRush follows a strict size budget:

| Category      | Max LOC   | Rationale                  |
| -------------- | ----------- | ------------------------------ |
| Core packages | 500-1,500 | Foundation must be minimal |
| Platforms     | ~500      | Thin adapters, no bloat    |
| Middleware    | ~300      | Single responsibility      |
| Extensions & Plugins | ~600 | Focused features           |

This ensures:

- Fast installation
- Quick cold starts
- Low memory footprint
- Transparent auditing
