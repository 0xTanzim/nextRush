This documentation site has been reorganized twice since v3: once to rename top-level folders
(`getting-started` → `start`, `api-reference` → `reference`, `examples` → `guides`), and again
to flatten and rename `reference/`, `internals/`, and `resources/`. Every old URL below still
resolves — this site redirects automatically via `apps/website/src/lib/legacy-redirects.ts`, so a
bookmark or an inbound link from an old blog post keeps working.

<Callout type="info" title="This page is about the docs site, not the framework API">
  For actual v3 → v4 breaking changes to packages, imports, and runtime behavior, see
  [Breaking Changes](/docs/migrate/breaking-changes) instead.
</Callout>

## Verifying a specific URL yourself

The table above is a curated summary. The authoritative, machine-checked source is the
`legacyRedirects` map itself:

```
apps/website/src/lib/legacy-redirects.ts
```

Every entry there is single-hop — no old URL ever redirects to another old URL before landing
on the current page — so any bookmark from any prior version of this site resolves in one
redirect, whether it targets a page moved once (like `resources/faq`) or a page moved twice
(like `api-reference/core/router`, which went through the T6 → B3 chain and now points straight
at `/docs/reference/router`).
