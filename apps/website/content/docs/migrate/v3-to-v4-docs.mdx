This documentation site has been reorganized twice since v3: once to rename top-level folders
(`getting-started` → `start`, `api-reference` → `reference`, `examples` → `guides`), and again
to flatten and rename `reference/`, `internals/`, and `resources/`. The table below maps every
old URL to its current location — use it to update bookmarks or inbound links.

<Callout type="info" title="This page is about the docs site, not the framework API">
  For actual v3 → v4 breaking changes to packages, imports, and runtime behavior, see
  [Breaking Changes](/docs/migrate/breaking-changes) instead.
</Callout>

## Top-level folder renames

| Old URL | New URL |
| --- | --- |
| `/docs/getting-started` | `/docs/start` |
| `/docs/api-reference` | `/docs/reference` |
| `/docs/examples` | `/docs/guides` |
| `/docs/internals` | `/docs/architecture` |
| `/docs/resources` | `/docs/help` |

## Reference — flattened from three levels to one

`reference/core/*`, `reference/middleware/*`, and `reference/plugins/*` all collapsed directly
into `reference/*`; `reference/adapters/*` was renamed to `reference/platforms/*`.

| `/docs/reference/core/types` | `/docs/reference/types` |

| `/docs/reference/core/runtime` | `/docs/reference/runtime` |

The mapping above covers every old `reference/*` path from both the original

## Resources → Help / Community

`resources/` retired: four reference pages became a new top-level `help/` folder, two
project-status pages moved into `community/`, and `package-catalog.mdx` was retired entirely as
a duplicate of the newer [Packages A-Z](/docs/reference/packages) reference page.

| Old URL | New URL |
| --- | --- |
| `/docs/resources` | `/docs/help` |
| `/docs/resources/faq` | `/docs/help/faq` |
| `/docs/resources/troubleshooting` | `/docs/help/troubleshooting` |
| `/docs/resources/glossary` | `/docs/help/glossary` |
| `/docs/resources/compatibility-matrix` | `/docs/help/compatibility-matrix` |
| `/docs/resources/roadmap` | `/docs/community/roadmap` |
| `/docs/resources/changelog` | `/docs/community/changelog` |
| `/docs/resources/package-catalog` | `/docs/reference/packages` (retired, not moved — see below) |

<Callout type="warn" title="Package Catalog was retired, not renamed">
  `resources/package-catalog.mdx`'s content — a per-package install-command list — duplicated
  the newer [Packages A-Z](/docs/reference/packages) reference page almost exactly. Rather than
  carry two overlapping pages forward, the old page was deleted and its URL now redirects
  straight to the replacement.
</Callout>
