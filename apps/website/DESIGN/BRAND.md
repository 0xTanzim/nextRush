# NextRush Brand Guidelines

- **Version:** 2.0
- **Status:** Stable
- **Owns:** the brand identity — vision, attributes, personality, logo usage, brand geometry, illustration, lighting, motion, photography, icons, hero artwork, documentation, OG/social/benchmark/CLI, voice, promise.
- **Companions:** `DESIGN.md` (WHY — the documentation design system), `TOKENS.md` (WHAT — the token values). Design implementation lives in `TOKENS.md`; the logo mark (`#F16913`) is the canonical source of truth.

---

# Brand Principles

These four principles are the foundation for every future visual decision. When a choice conflicts, the principle wins.

- **Recognition before decoration.** Brand elements exist to be recognized, not to embellish. If a mark, color, or motion doesn't aid recognition, remove it.
- **Consistency before creativity.** A familiar pattern beats a clever one-off. Every surface should feel like the same product.
- **Craftsmanship before trends.** Quality, restraint, and precision outlast any trend. We ship what we'd defend in five years.
- **Engineering before marketing.** The product's substance leads; the brand communicates it honestly rather than amplifying it.

> **Art direction, not tokens:** hero lighting, ambient glows, particle opacity, and blur are *art direction* — expressive choices for Brand-Mode hero artwork — not design tokens. They live as guidance under [Hero Artwork](#hero-artwork) and are governed by the Documentation Mode rules in `DESIGN.md` ("no glow, no decorative shadows"). They are never consumed as tokens by components.

# Brand Vision

NextRush is a modern backend framework built for developers who value explicit architecture, simplicity, and long-term maintainability.

The brand should communicate engineering quality rather than marketing.

The experience should feel calm, confident, and carefully crafted.

---

# Logo

The logo is the primary visual identifier.

It should remain simple, recognizable, and consistent across every platform.

The icon and wordmark should always maintain their proportions.

Never redraw the logo.

---

# Logo Meaning

The logo represents:

- Forward movement
- Continuous flow
- Composable architecture
- Connection
- Engineering precision

The flowing geometry also becomes the foundation of the entire visual language.

---

# Logo Usage

Preferred usage:

✓ Icon + Wordmark

Alternative:

✓ Icon only

Use the icon only when space is limited.

Examples:

- Favicon
- CLI
- Browser tab
- Mobile
- Social avatar

---

# Clear Space

Maintain sufficient spacing around the logo.

Minimum spacing should equal approximately the width of the logo's inner curve.

Nothing should visually compete with the logo.

---

# Minimum Size

Icon

16px minimum

Wordmark

120px minimum

Smaller sizes should use the icon only.

---

# Color Usage

The logo should primarily use the brand orange `#F16913`.

Monochrome versions are acceptable when necessary.

Never introduce additional brand colors.

---

# Backgrounds

Preferred:

- White
- Warm paper
- Graphite
- Neutral surfaces

Avoid:

- Busy photography
- Heavy gradients
- Patterned backgrounds
- Low contrast surfaces

---

# Brand Geometry

The curves inside the logo define the visual language.

Those curves should inspire:

- Hero artwork
- Background graphics
- Dividers
- Empty states
- Benchmark graphics
- Open Graph images
- Social media assets

Avoid generic blobs, circles, or unrelated abstract graphics.

Every illustration should feel like it belongs to the logo.

---

# Illustration Style

Illustrations should be:

- Abstract
- Architectural
- Minimal
- Layered
- Soft
- Geometric

Avoid:

- 3D renders
- Cartoon illustrations
- Stock illustrations
- AI fantasy artwork
- Random decorative graphics

---

# Lighting

Ambient lighting is part of the brand.

Lighting should feel environmental rather than decorative.

Use:

- Large soft radial lighting
- Warm highlights
- Low opacity
- Gentle gradients

Avoid:

- Neon glow
- Strong bloom
- Lens flares
- Colored shadows

---

# Motion

Motion should communicate responsiveness.

Not entertainment.

Recommended:

- Soft fade
- Small elevation
- Gentle transitions
- Slow background movement

Avoid:

- Bounce
- Elastic effects
- Fast looping animations
- Excessive parallax

---

# Photography

If photography is used:

Prefer:

- Workspaces
- Engineering
- Minimal setups
- Hardware
- Architecture

Avoid:

- Generic office stock photos
- Smiling business teams
- Marketing lifestyle imagery

---

# Icons

Icons should be:

- Rounded
- Simple
- Consistent stroke
- Minimal detail

Brand orange should only highlight interactive or important actions.

---

# Hero Artwork

Hero sections should use custom artwork inspired by the logo geometry.

Recommended elements:

- Flowing ribbons
- Ambient lighting
- Subtle particles
- Soft gradients
- Architectural composition

The artwork should support the content—not compete with it.

---

# Documentation

Documentation should prioritize readability.

Branding exists to support navigation and identity.

Content should always remain the visual priority.

---

# Open Graph Images

Every Open Graph image should include:

- Logo
- Product name
- Clean typography
- Brand background
- Subtle ribbon artwork

Avoid text-heavy compositions.

---

# Social Media

Brand consistency should remain across:

- GitHub
- X
- LinkedIn
- Discord
- YouTube
- Documentation
- Blog

Users should immediately recognize NextRush regardless of platform.

---

# Benchmark Dashboard

Benchmark pages should feel like engineering tools.

Avoid marketing graphics.

Use:

- Clean charts
- Neutral surfaces
- Brand highlights
- Clear hierarchy

---

# CLI

Even terminal experiences should reflect the brand.

Use:

- Logo
- Consistent spacing
- Minimal color
- Orange highlights only when meaningful

---

# Brand Voice

The visual style should match the written voice.

Writing should be:

- Clear
- Honest
- Technical
- Direct
- Friendly

Avoid:

- Hype
- Buzzwords
- Marketing exaggeration
- Clickbait language

---

# Inspiration

The brand philosophy is inspired by products that balance engineering excellence with thoughtful design.

- GitHub
- Linear
- Vercel
- Stripe
- Apple Developer
- Arc Browser

The objective is not imitation.

The objective is to achieve the same level of clarity, consistency, and craftsmanship while expressing the unique identity of NextRush.

---

# Brand Promise

Every interaction with NextRush should reinforce one idea:

> Engineering can be powerful without being complicated.

The visual identity should quietly communicate confidence, trust, and craftsmanship while allowing developers to stay focused on building software.
