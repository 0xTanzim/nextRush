# Audit workspace

This directory is copied to `<repository-root>/.audit/` by `scripts/init-audit.sh`.

Keep the audit reproducible and compact. Link to raw profiler outputs and long logs rather than pasting everything into every Markdown file. Record both positive and negative evidence. Do not commit secret values or environment dumps that contain credentials.

Suggested update order: plan → evidence ledger → findings → comparison → experiments → validation → final report.
